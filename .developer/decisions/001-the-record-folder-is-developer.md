# 001 The record folder is `.developer/`

**Date:** 2026-11-16, the owner.

**Context.** The loops that change a product need one place for their record: the steps, the
measures, the friction, the decisions. The folder is named after the kind of project, so it says
which loop runs there: `.developer/` for development, `.migrator/` for a migration.

**Decision.** Kofflard is a development project and keeps its record in `.developer/`, with the
core files 000 to 600 and `decisions/`. Kofflard is the first product to try the folder; Tomorrow
is the second.

**Why.** Kofflard is small, real and ours, and all its suites run without a device, so the folder
can be tried on real work at little cost before the tools and the other cases use it.

**What follows.** `.my/` stays the owner's scratch space and keeps the designs. What the folder
lacks or holds for nothing is written in the friction log with `.developer` under Where.
